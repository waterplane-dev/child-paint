# positioning

### R-positioning-001 · shipped
Every live object (shape, selection, text, picked-up thing) has three large knobs on strings, whatever its size: move (hangs below), size (off the corner) and turn (above). The finger holds the knob, so the object stays in view instead of hidden under the fingertip.
- asked: 2026-09-24 (session ecc658e0)
- shipped: working tree, uncommitted

### R-positioning-002 · shipped
While a shape, selection box or text box is being dragged out, the corner being pulled hangs on a string above the finger, so the child sees it. A plain tap with a shape tool stamps a ready-made 3 cm shape.
- asked: 2026-09-24 (session ecc658e0)
- shipped: working tree, uncommitted

### R-positioning-003 · shipped
Things already placed can be picked up again later with the hand tool (the old select tool): tapping a shape, text, brush line or earlier-moved thing lifts it, with knobs, and it carries along whatever was drawn or poured onto it. Tapping empty paper still drags a rectangle selection.
- asked: 2026-09-24 (session ecc658e0)
- shipped: working tree, uncommitted
